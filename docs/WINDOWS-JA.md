# Windowsでの導入手順

対象は、ESP32-S31-Korvo-1、接続された800×480 RGB LCD、タッチパネル、16 MiBフラッシュ／16 MiB PSRAMの構成です。ほかの基板やLCDは未確認です。

1. [Releases](https://github.com/pokorino/BasiliskII-ESP32-S31/releases)から `BasiliskII-S31-Windows.zip` をダウンロードし、すべて展開します。Windows x64用です。Pythonのインストールは不要です。
2. 基板のUSBシリアル端子をWindows PCに接続します。テストした構成ではSilicon Labs CP210xとして認識されました。COMポートが出ない場合は、お使いのUSBシリアル変換器に合ったドライバーを導入してください。
3. 展開先の `flash.cmd` をダブルクリックし、表示されたCOMポートから基板の番号を入力します。書き込み確認で `YES` と入力します。照合が終わり `Flash verified` と出るまで電源やケーブルを外さないでください。
4. 書き込みツールは、ブートローダー・パーティションテーブル・本体を書き換えます。既存のフラッシュ構成にあるデータは使えなくなる場合があります。microSDカードは書き込みません。NVS設定は意図的には消去しません。
5. FAT32のmicroSDカードの一番上の階層に、自分で用意した対応ROMを `MAC_ROM.dat`、起動可能なMac OSディスクイメージを `mac1.HFV` という名前で保存します。ROMとOSは配布していません。仮想ディスクは書き込み可能で開き、必要に応じHFS管理情報を更新するため、使用前にバックアップしてください。
6. 基板の電源を切ってmicroSDを挿入し、電源を入れます。何も押さなければMacが自動起動します。起動時は画面が黒いままになる時間があります。
7. 設定画面を開くには、電源を入れて少し待ってから画面を押し続けるか、USBキーボードのキーを押し続けます。実機では、電源投入前から画面を押したままだと検出されない場合がありました。設定画面ではRAM、音声、ROM、起動ディスクを選び、`SAVE AND START`で保存して起動します。

初期RAMは12 MiBですが、以前保存した設定がある場合はそちらが優先されます。ROMやディスクの変更機能、音声の実再生、USBハブ、ほかのボード構成は未確認です。Mac OSを終了すると画面は黒くなりますが、基板は通電中なので電源スイッチで切ってください。

詳しい注意事項と実機確認範囲は[英語README](../README.md)をご覧ください。
